Kategorie 1

Základy síťových socketů a knihovna socket

Co je to Socket?

  • Koncový bod komunikace: Rozhraní mezi aplikací a síťovým zásobníkem operačního systému.
  • Kombinace údajů: IP adresa + Port + Transportní protokol (TCP/UDP).
  • Standardní knihovna: V Pythonu vestavěná knihovna import socket.

Typy socketů

TCP (SOCK_STREAM)
  • Spojovaný protokol (Handshake).
  • Garantované doručení a pořadí dat.
  • Vhodný pro HTTP, SSH, FTP.
UDP (SOCK_DGRAM)
  • Bezspojový protokol.
  • Rychlý, bez garance doručení.
  • Vhodný pro DNS, streaming, hry.

Vytvoření TCP Klienta

Připojení k webovému serveru a odeslání HTTP požadavku:

import socket

# 1. Vytvoření TCP socketu (IPv4 + TCP)
client = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

# 2. Připojení k cíli (IP / hostname, port)
client.connect(("example.com", 80))

# 3. Odeslání HTTP požadavku (data musí být bajty: b"...")
request = "GET / HTTP/1.1\r\nHost: example.com\r\nConnection: close\r\n\r\n"
client.sendall(request.encode("utf-8"))

# 4. Přijetí odpovědi (max 4096 bajtů)
response = client.recv(4096)
print(response.decode("utf-8"))

# 5. Uzavření spojení
client.close()

Vytvoření TCP Serveru

Jednoduchý server naslouchající na portu 9999:

import socket

server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
server.bind(("0.0.0.0", 9999))  # Naslouchá na všech rozhraních
server.listen(5)               # Fronta pro max 5 čekajících spojení

print("[*] Server naslouchá na portu 9999...")

while True:
    client_socket, addr = server.accept()  # Blokující volání
    print(f"[+] Přijato spojení z {addr[0]}:{addr[1]}")
    
    data = client_socket.recv(1024)
    print(f"[<] Přijato: {data.decode('utf-8')}")
    
    client_socket.sendall(b"Ahoj z Python serveru!\n")
    client_socket.close()

Práce s UDP Sockets

U UDP nepoužíváme connect() ani accept(), ale sendto() a recvfrom():

import socket

# UDP Client
udp_client = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
target = ("127.0.0.1", 5005)

# Odeslání zprávy přímo na adresu
udp_client.sendto(b"Testovaci UDP zprava", target)

# Přijetí odpovědi a adresy odesílatele
data, addr = udp_client.recvfrom(1024)
print(f"Odpověď od {addr}: {data.decode()}")

udp_client.close()

Ošetření chyb a timeouty

  • Síťové operace mohou selhat nebo zamrznout.
  • Nastavení timeoutu: s.settimeout(2.0).
  • Ošetření výjimek pomocí try-except socket.error.
import socket

s = socket.socket()
s.settimeout(2.0)  # Čekat max 2 sekundy

try:
    s.connect(("192.168.1.50", 80))
    print("Port je otevřený!")
except socket.timeout:
    print("Spojení vypršelo (Timeout).")
except socket.error as e:
    print(f"Chyba spojení: {e}")
finally:
    s.close()

Kategorie 2

Tvorba vlastních síťových nástrojů

Nástroj 1: Jednoduchý TCP Port Scanner

Zjištění otevřených portů pomocí connect_ex() (vrací 0 při úspěchu):

import socket

target = "127.0.0.1"
ports = [21, 22, 80, 443, 8080]

print(f"Skenuji cíl: {target}")

for port in ports:
    s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    s.settimeout(1.0)
    result = s.connect_ex((target, port))  # Vrací 0 při úspěchu, jinak chybový kód
    
    if result == 0:
        print(f"[+] Port {port}: OTEVŘENÝ")
    else:
        print(f"[-] Port {port}: ZAVŘENÝ")
    s.close()

Zrychlení scanneru: Vícevláknové skenování

Použití concurrent.futures.ThreadPoolExecutor pro paralelní testování portů:

import socket
from concurrent.futures import ThreadPoolExecutor

def scan_port(target, port):
    with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
        s.settimeout(1.0)
        if s.connect_ex((target, port)) == 0:
            return port
    return None

target = "127.0.0.1"
print("[*] Spouštím paralelní skenování portů 1-1024...")

with ThreadPoolExecutor(max_workers=50) as executor:
    results = executor.map(lambda p: scan_port(target, p), range(1, 1025))
    for open_port in filter(None, results):
        print(f"[+] Nalezen otevřený port: {open_port}")

Nástroj 2: Banner Grabber

Zjištění verze a typu běžící služby na otevřeném portu:

import socket

def grab_banner(ip, port):
    try:
        s = socket.socket()
        s.settimeout(2.0)
        s.connect((ip, port))
        
        # Některé služby pošlou banner samy (SSH, FTP), jiné vyžadují požadavek
        if port == 80:
            s.send(b"HEAD / HTTP/1.1\r\nHost: " + ip.encode() + b"\r\n\r\n")
            
        banner = s.recv(1024).decode("utf-8", errors="ignore").strip()
        return banner
    except Exception as e:
        return f"Chyba: {e}"
    finally:
        s.close()

print("SSH Banner:", grab_banner("127.0.0.1", 22))

Nástroj 3: Echo Server s obsluhou klientů

Jednoduchý server, který klientovi vrací vše, co klient pošle:

import socket

server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
server.bind(("127.0.0.1", 8888))
server.listen(1)
print("[*] Echo server běží na 127.0.0.1:8888")

conn, addr = server.accept()
print(f"[+] Klient připojen: {addr}")

while True:
    data = conn.recv(1024)
    if not data or data.strip() == b"exit":
        break
    conn.sendall(b"ECHO: " + data)

conn.close()
server.close()
print("[*] Server ukončen.")

Kategorie 3

Nízkoúrovňový přístup a tvorba paketů v knihovně Scapy

Co je to Scapy?

  • Výkonný síťový nástroj: Python knihovna pro tvorbu, odchytávání, modifikaci a odesílání síťových paketů.
  • Práce s vrstvami: Každá OSI vrstva je samostatný Python objekt (Ether(), IP(), TCP(), ICMP()).
  • Injektování paketů: Umožňuje vytvářet i neplatné nebo vlastní pakety (vhodné pro pentesting a ladění sítí).

Skládání paketů v Scapy

Vrstvy se spojují pomocí operátoru lomenítka /:

from scapy.all import IP, TCP, ICMP, Ether, ls

# Vytvoření IP paketu s cíl adresou
ip_pkt = IP(dst="8.8.8.8")

# Přidání TCP vrstvy s cílovým portem 80 (SYN paket)
syn_pkt = IP(dst="1.1.1.1") / TCP(dport=80, flags="S")

# ICMP Ping paket s Ethernetovou vrstvou
ping_pkt = Ether() / IP(dst="192.168.1.1") / ICMP()

# Zobrazení detailů paketu
syn_pkt.show()

Odesílání a příjem paketů v Scapy

Odeslání bez odpovědi
  • send(pkt) – Odeslání na L3 (IP).
  • sendp(pkt) – Odeslání na L2 (Ethernet).
Odeslání s čekáním na odpověď
  • sr(pkt) – Odeslat a přijmout na L3.
  • sr1(pkt) – Odeslat a přijmout 1. odpověď.
  • srp(pkt) – Odeslat a přijmout na L2.

Nástroj 4: Vlastní ICMP Ping v Scapy

Odeslání jednoho ICMP Echo Requestu a přečtení odpovědi:

from scapy.all import IP, ICMP, sr1

target_ip = "8.8.8.8"

# Vytvoření ICMP paketu
pkt = IP(dst=target_ip) / ICMP()

# Odeslání a čekání na 1. odpověď (timeout 2s)
reply = sr1(pkt, timeout=2, verbose=False)

if reply:
    print(f"[+] Cíl {target_ip} ODPOVÍDÁ! TTL={reply.ttl}")
else:
    print(f"[-] Cíl {target_ip} neodpovídá.")

Nástroj 5: ARP Scanner (Objevení zařízení v LAN)

Odeslání ARP dotazu na broadcast pro rozsah IP adres:

from scapy.all import ARP, Ether, srp

def arp_scan(ip_range):
    # ARP dotaz obalený v Ethernet broadcast rámci (ff:ff:ff:ff:ff:ff)
    arp_req = ARP(pdst=ip_range)
    broadcast = Ether(dst="ff:ff:ff:ff:ff:ff")
    packet = broadcast / arp_req
    
    answered, _ = srp(packet, timeout=2, verbose=False)
    
    print("IP adresa\t\tMAC adresa")
    print("-" * 42)
    for sent, received in answered:
        print(f"{received.psrc}\t\t{received.hwsrc}")

# Spuštění skenu pro lokální síť
arp_scan("192.168.1.0/24")

Nástroj 6: Paketový Sniffer

Odchytávání a živá analýza letících paketů pomocí sniff():

from scapy.all import sniff, IP, TCP

def packet_callback(packet):
    if packet.haslayer(IP):
        ip_src = packet[IP].src
        ip_dst = packet[IP].dst
        proto = packet[IP].proto
        print(f"[Paket] {ip_src} -> {ip_dst} (Protokol: {proto})")
        
        if packet.haslayer(TCP):
            print(f"        TCP Port: {packet[TCP].sport} -> {packet[TCP].dport}")

print("[*] Spouštím sniffer (10 paketů)...")
# Filter používá BPF syntaxi jako Wireshark/tcpdump
sniff(filter="ip", prn=packet_callback, count=10)

Kategorie 4

Doporučené postupy, bezpečnost a cvičení

Práva v Linuxu: Sudo / Root

  • Vyšší oprávnění: Práce s raw sockety a knihovnou Scapy vyžaduje root práva.
  • Spuštění skriptu: Použijte sudo python3 skript.py.
  • Virtuální prostředí: Při použití venv se ubezpečte o správné cestě: sudo ./venv/bin/python3 skript.py.

Etické zásady a bezpečnost

Varování
  • Skenování cizích sítí bez povolení je nelegální!
  • Nepoužívejte sniffery a scannery na veřejných Wi-Fi.
Doporučení
  • Testujte výhradně v localhost (127.0.0.1) nebo ve vlastní Docker síti.
  • Využívejte skripty pro automatizaci vlastní správy sítí.

Samostatné mini-cvičení

  1. Napište skript my_scanner.py, který přijme z argumentu IP adresu.
  2. Otestuje porty 22, 80 a 443 pomocí socket.connect_ex().
  3. U otevřených portů se pokusí stáhnout Banner (prvních 100 bajtů).
  4. Bonus výzva: Pomocí Scapy pošlete SYN paket na port 80 a zkontrolujte, zda vrátí vlajku SA (SYN-ACK).

Co si zapamatovat

  • socket je standardní modul pro TCP/UDP komunikaci.
  • connect_ex() usnadňuje zjišťování stavu portů bez výjimek.
  • Scapy umožňuje nízkoúrovňově skládat jakékoliv pakety pomocí /.
  • sniff() a srp() slouží k odchytávání a ARP skenování.
