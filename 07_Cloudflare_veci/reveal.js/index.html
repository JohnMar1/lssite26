Kategorie 1

Vlastní doména a Cloudflare

Máme vlastní doménu!

  • Každý účastník Letní školy sítí dostal svoji vlastní doménu.
  • Doménu použijeme k publikování vašich projektů do celého internetu.

Co je to doména (DNS)?

  • Lidsky čitelná adresa (např. mojedomena.cz).
  • Nahrazuje těžko zapamatovatelné číselné IP adresy.
  • Systém DNS překládá názvy domén na IP adresy.

Co je Cloudflare?

  • Celosvětová síť serverů a DNS poskytovatel.
  • Chrání servery před útoky (DDoS).
  • Automaticky poskytuje bezplatné SSL certifikáty (HTTPS).

Jak se běžně publikují služby?

  • Potřebujete od poskytovatele veřejnou IP adresu.
  • Musíte na domácím routeru nastavit Port Forwarding.
  • Vaše zařízení je přímo vystaveno útokům z internetu.

Proč je veřejná IP problém?

  • Většina domácností i škol veřejnou IP adresu nemá.
  • Poskytovatelé internetu si za veřejnou IP účtují poplatky.
  • Nesprávně nastavený router může ohrozit celou síť.

Kategorie 2

Princip Cloudflare Tunnel

Co je Cloudflare Tunnel?

  • Šifrovaný tunel mezi vaším počítačem a sítí Cloudflare.
  • Umožňuje publikovat služby bez veřejné IP adresy.

Hlavní výhoda tunelu

  • Nemusíte se dotýkat nastavení vašich routerů.
  • Funguje i na školní síti nebo mobilním hotspotu.
  • Vaše služba je okamžitě dostupná pro celý svět.

Jak tunel funguje?

  • Náš počítač naváže odchozí spojení do Cloudflare.
  • Návštěvník přistupuje na servery Cloudflare.
  • Cloudflare přeposílá provoz přes tunel k nám.

Bezpečnostní přínos

  • Všechny příchozí porty na vašem počítači zůstanou zavřené.
  • Útočníci nevidí vaši skutečnou IP adresu.

Kategorie 3

Instalace a přihlášení cloudflared

Co je program cloudflared?

  • Pomocný program v terminálu Linuxu.
  • Zajišťuje udržování a správu spojení tunelu.

Krok 1: Instalace cloudflared

V terminálu zadejte příkaz pro instalaci:


sudo apt update
sudo apt install -y cloudflared

Krok 2: Ověření instalace

Zkontrolujte správné nainstalování programu:


cloudflared --version

Krok 3: Přihlášení k účtu

Propojíme program s vaším Cloudflare účtem:


cloudflared tunnel login

Krok 4: Autorizace domény

  1. V terminálu se zobrazí webový odkaz.
  2. Otevřete odkaz v prohlížeči.
  3. Přihlaste se a vyberte vaši přidělenou doménu.
  4. Potvrďte autorizaci tlačítkem.

Kategorie 4

Vytvoření a konfigurace tunelu

Krok 5: Vytvoření tunelu

Vytvoříme novou instanci tunelu s názvem moje-lss:


cloudflared tunnel create moje-lss

Co se stalo?

  • Vytvořilo se unikátní ID vášho tunelu.
  • Uložil se certifikát a klíč do složky ~/.cloudflared/.

Krok 6: Propojení domény s tunelem

Nasměrujeme subdoménu (např. web) na náš tunel:


cloudflared tunnel route dns moje-lss web.mojedomena.cz

Nahraďte mojedomena.cz vaší skutečnou doménou.

Co je to CNAME záznam?

  • Příkaz automaticky vytvoří CNAME záznam v DNS.
  • Nasměruje vaši doménu na unikátní adresu tunelu v Cloudflare.

Krok 7: Vytvoření konfigurace

Otevřeme soubor pro nastavení směrování provozu:


nano ~/.cloudflared/config.yml

Ukázka config.yml


tunnel: MOJE_TUNNEL_ID
credentials-file: /home/student/.cloudflared/MOJE_TUNNEL_ID.json

ingress:
  - hostname: web.mojedomena.cz
    service: http://localhost:80
  - service: http_status:404

Kategorie 5

Spuštění a testování služby

Krok 8: Spuštění tunelu

V terminálu spustíme náš tunel:


cloudflared tunnel run moje-lss

Testování v prohlížeči

  1. Otevřete webový prohlížeč.
  2. Zadejte adresu: https://web.mojedomena.cz.
  3. Uvidíte vaši webovou stránku spuštěnou na vašem počítači!

Automatický SSL certifikát

  • Cloudflare automaticky zabezpečil komunikaci pomocí HTTPS.
  • Uživatelé vidí zelený zámek v prohlížeči.
  • Nemusíte ručně generovat žádné certifikáty.

Zabezpečení firewallem UFW

Zabezpečíme náš počítač lokálním firewallem:


# Zapnutí firewallu UFW
sudo ufw enable

# Zablokování všech příchozích spojení
sudo ufw default deny incoming

Tunel bude stále fungovat, protože využívá odchozí spojení!

Kategorie 6

Samostatné cvičení a shrnutí

Samostatné cvičení

  1. Nainstalujte program cloudflared na váš systém.
  2. Přihlaste se k účtu pomocí cloudflared tunnel login.
  3. Vytvořte tunel moje-lss a nastavte směrování domény.
  4. Spusťte tunel a vyzkoušejte přístup z mobilního telefonu přes HTTPS.

Shrnutí modulu

  • Rozumíme funkci domén a principu Cloudflare.
  • Umíme publikovat služby bez veřejné IP adresy.
  • Používáme nástroj cloudflared a tunely.
  • Naše webové aplikace i servery jsou bezpečně dostupné v internetu.
