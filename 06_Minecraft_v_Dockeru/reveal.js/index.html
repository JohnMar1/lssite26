Kategorie 1

Úvod a základní pojmy

Co je to herní server?

  • Program běžící na počítači, ke kterému se připojují hráči.
  • Počítá fyziku, uchovává bloky a synchronizuje hráče.
  • Klasicky vyžaduje instalaci Javy a nastavení systému.

Proč použít Docker?

  • Nemusíme instalovat Javu: Vše je připraveno uvnitř kontejneru.
  • Žádný nepořádek: Server běží v izolované složce.
  • Snadné spuštění: Stačí jediný příkaz.

Obraz itzg/minecraft-server

  • Hotový balíček připravený komunitou.
  • Obsahuje v sobě Minecraft i potřebnou verzi Javy.
  • Stáhne se automaticky z internetu při prvním spuštění.

Kategorie 2

Konfigurace docker-compose.yml

Co je docker-compose.yml?

  • Textový soubor, který funguje jako recept.
  • Říká Dockeru, jaký server chceme spustit.
  • Zapisuje se v přehledném formátu YAML.

Krok 1: Vytvoření složky

V terminálu si nejprve vytvoříme složku pro náš server:


# Vytvořit složku mc-server
mkdir mc-server

# Přepnout se do vytvořené složky
cd mc-server

Krok 2: Vytvoření souboru

Otevřeme textový editor nano:


nano docker-compose.yml

Ukázka docker-compose.yml


version: '3.8'

services:
  mc-server:
    image: itzg/minecraft-server:latest
    container_name: mc-server
    ports:
      - "25565:25565"
    environment:
      EULA: "TRUE"
      TYPE: "PAPER"
      VERSION: "1.20.4"
      MEMORY: "2G"
    volumes:
      - ./data:/data
    restart: unless-stopped

Vysvětlení: Souhlas s EULA


environment:
  EULA: "TRUE"
  • Souhlas s podmínkami použití od tvůrců hry Mojang.
  • Bez tohoto řádku se server z bezpečnostních důvodů nespustí.

Vysvětlení: Typ a verze serveru


environment:
  TYPE: "PAPER"
  VERSION: "1.20.4"
  • TYPE: "PAPER" — Zrychlená verze serveru (doporučeno).
  • VERSION: "1.20.4" — Přesná verze hry Minecraft.

Vysvětlení: Paměť RAM


environment:
  MEMORY: "2G"
  • Určuje, kolik operační paměti může server využít.
  • Pro běžné hraní v učebně stačí 2G (2 Gigabajty).

Kategorie 3

Síťové porty a Úložiště

Co je to síťový port?

  • Číslo dveří, na kterých síťová služba poslouchá.
  • Minecraft Java Edition používá port 25565.

Mapování portu v Compose


ports:
  - "25565:25565"
  • První číslo: Port na vašem počítači.
  • Druhé číslo: Port uvnitř Docker kontejneru.

Proč potřebujeme Úložiště (Volume)?

  • Docker kontejnery neukládají data trvale.
  • Bez úložiště by se po vypnutí kontejneru smazal celý svět.

Nastavení Volume v Compose


volumes:
  - ./data:/data
  • Propojí složku ./data na vašem počítači se složkou uvnitř kontejneru.
  • Veškeré stavby a mapa zůstanou bezpečně uloženy na disku.

Co se uloží do složky ./data?

  • world/ — Soubory mapy a krajiny.
  • server.properties — Hlavní nastavení hry.
  • ops.json — Seznam administrátorů.

Kategorie 4

Spuštění serveru a připojení

Spuštění příkazem up

V terminálu ve složce se souborem zadejte:


docker-compose up -d

Co znamená parametr -d?

  • Spustí kontejner na pozadí (Detached mode).
  • Terminál zůstane volný pro další příkazy.

Sledování startu v logu

Stahování a generování světa sledujeme příkazem:


docker-compose logs -f

Sledování ukončíme stiskem kláves Ctrl + C.

Jak poznám, že server běží?

V logu se objeví řádek potvrdzující dokončení:


[Server thread/INFO]: Done (18.421s)! For help, type "help"

Připojení ze hry Minecraft

  1. Spusťte Minecraft klient (verze 1.20.4).
  2. Vyberte Hra pro více hráčů (Multiplayer).
  3. Zvolte Přímé připojení (Direct Connection).
  4. Zadejte adresu: localhost.

Kategorie 5

Admin práva a správa

Co je RCON konzole?

  • Nástroj pro posílání příkazů do serveru z terminálu.
  • Umožňuje spravovat server bez přihlášení do hry.

Udělení admin práv (OP)

V terminálu zadejte příkaz:


docker exec -i mc-server rcon-cli op student

Nahraďte student vaším herním jménem (Nickem).

Základní příkazy v konzoli


# Nastavení dne ve hře
docker exec -i mc-server rcon-cli time set day

# Změna herního módu na Creative
docker exec -i mc-server rcon-cli gamemode creative student

Úprava nastavení serveru

  1. Otevřete soubor ./data/server.properties v nano.
  2. Upravte požadovaný parametr (např. pvp=false).
  3. Uložte soubor.

Restartování kontejneru

Aby se změny v nastavení projevily, restartujeme server:


docker-compose restart

Kategorie 6

Zálohování a cvičení

Jak vytvořit zálohu světa?

Všechna data jsou ve složce ./data, stačí ji zabalit:


tar -czvf zaloha-mc.tar.gz ./data

Jak obnovit svět ze zálohy?


# 1. Zastavit server
docker-compose down

# 2. Obnovit složku data ze zálohy
tar -xzvf zaloha-mc.tar.gz

# 3. Opět spustit server
docker-compose up -d

Samostatné cvičení

  1. Vytvořte složku ~/muj-mc-server.
  2. Vytvořte soubor docker-compose.yml s verzí 1.20.4 a typem PAPER.
  3. Spusťte server příkazem docker-compose up -d.
  4. Zkontrolujte stav pomocí docker-compose logs -f.
  5. Připojte se ze hry na adresu localhost.

Shrnutí modulu

  • Víme, jak vytvořit Minecraft server v Dockeru.
  • Rozumíme souboru docker-compose.yml.
  • Umíme namapovat port 25565 a uložit data na disk.
  • Umíme spravovat admin práva přes RCON.
