Teorie a výhody kontejnerizace

Tradiční instalace vs. Docker

Tradiční instalace

  • Ruční správa konkrétní verze Javy (Java 8, 17, 21).
  • Složité spouštění na pozadí (screen, tmux, systemd).
  • Riziko závislostí a konfliktů v hostitelském OS.
  • Obtížná přenositelnost na jiný server.

Docker řešení

  • Java i server jsou zabalené v jediném obrazu.
  • Jednoduché spouštění přes docker-compose up -d.
  • Striktní izolace paměti, procesů a souborů.
  • Plná přenositelnost mezi systémy.

Obraz itzg/minecraft-server

  • Oficiálně podporovaný komunitní obraz na Docker Hubu.
  • Podpora typů serverů: Vanilla, Paper, Spigot, Forge, Fabric, Purpur.
  • Konfigurace: Vše se nastavuje přes proměnné prostředí (Environment variables).
  • Automatizace: Automatické stažení požadované verze Minecraftu i Javy.

Konfigurace docker-compose.yml

Struktura souboru docker-compose.yml


version: '3.8'

services:
  mc-server:
    image: itzg/minecraft-server:latest
    container_name: mc-server
    ports:
      - "25565:25565"
    environment:
      EULA: "TRUE"
      TYPE: "PAPER"
      VERSION: "1.20.4"
      MEMORY: "2G"
      MOTD: "Letní škola sítí Minecraft Server"
    volumes:
      - ./data:/data
    restart: unless-stopped

Klíčové Environment proměnné

Proměnná Výchozí / Příklad Popis
EULA "TRUE" Souhlas s licencí Mojang EULA (povinné)
TYPE PAPER / SPIGOT / VANILLA Typ Minecraft serveru (Paper pro vyšší výkon)
VERSION LATEST / 1.20.4 Verze hry Minecraft
MEMORY 1G / 2G / 4G Maximální alokovaná paměť RAM
MOTD "Text zprávy" Zpráva dne v seznamu serverů
OPS "student" Seznam uživatelů s admin právy

Síťové porty a Persistence dat

Mapování síťových portů

  • Minecraft Java Edition používá výchozí port 25565 (TCP).
  • Zápis v Compose: - "25565:25565" (Port hostitele : Port kontejneru).
  • Běh více serverů na 1 stroji:
    - "25565:25565" (1. server)
    - "25566:25565" (2. server)

Persistence dat (Volumes)

  • Kontejnery jsou bezstavové (stateless).
  • Bez volume se při zastavení kontejneru smazou všechny změny a světy.
  • Bind Mount: - ./data:/data propojí lokální složku na disku se složkou v kontejneru.
  • Obsah složky ./data: `world/`, `server.properties`, `plugins/`, `ops.json`.

Spuštění, Logy a RCON Správa

Spuštění serveru a sledování logů

  1. Vytvoření adresáře: mkdir mc-server && cd mc-server
  2. Spuštění na pozadí: docker-compose up -d
  3. Sledování logů: docker-compose logs -f
  4. Připojení z klienta: Direct Connection na adresu localhost (port 25565).

Správa konzole přes RCON

Spouštění příkazů uvnitř běžícího kontejneru:


# Udělení OP práv hráči "student"
docker exec -i mc-server rcon-cli op student

# Změna času ve hře
docker exec -i mc-server rcon-cli time set day

# Zapnutí seznamu povolených hráčů (whitelist)
docker exec -i mc-server rcon-cli whitelist on

Úprava server.properties

  • Soubor se nachází v lokální složce ./data/server.properties.
  • Umožňuje změnit herní pravidla (pvp, difficulty, max-players).
  • Aplikace změn se provede restartem kontejneru: docker-compose restart.

Pluginy, Bedrock a Zálohování

Rozšíření serveru (Pluginy & Bedrock)

  • Pluginy: Nahrání .jar souborů do složky ./data/plugins/ + restart kontejneru.
  • Bedrock podpora (GeyserMC): Připojení z mobilů a konzolí.
  • Nutné namapovat UDP port v Compose: - "19132:19132/udp".

Zálohování a obnova světa

Díky oddělené složce ./data je archivace jednoduchá:


# Vytvoření zálohy světa
tar -czvf zaloha-mc.tar.gz ./data

# Obnova ze zálohy
docker-compose down
rm -rf ./data
tar -xzvf zaloha-mc.tar.gz
docker-compose up -d

Samostatné cvičení

  1. Vytvořte složku ~/muj-mc-server a soubor docker-compose.yml.
  2. Nakonfigurujte Paper server verze 1.20.4 s pamětí 2G.
  3. Spusťte server a ověřte funkčnost přes docker-compose logs -f.
  4. Připojte se ze svého Minecraft klienta a udělejte se operátorem (OP).
