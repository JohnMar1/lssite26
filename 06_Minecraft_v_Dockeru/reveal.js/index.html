Blok 1: Tradiční server vs. Docker

Proč stavět herní servery v Dockeru?

Tradiční instalace ❌

  • Nutná ruční instalace konkrétní verze Javy (Java 8, 17, 21).
  • Složité spouštění na pozadí (screen, tmux, systemd service).
  • Riziko poškození hostitelského OS při pádu příkazů.
  • Těžká přenositelnost na jiný server.

Docker řešení 🚀

  • Java i server jsou zabalené v jediném Image.
  • Běh na pozadí pomocí docker-compose up -d.
  • Striktní izolace paměti a CPU.
  • 100% přenositelnost — funguje stejně všude.

Náš hlavní nástroj: itzg/minecraft-server

  • Nejoblíbenější Docker Image pro Minecraft na světě (>100M stažení).
  • Podpora všech typů serverů: Vanilla, Paper, Spigot, Forge, Fabric, Purpur, BungeeCord.
  • Konfigurace bez přepisování souborů: Vše nastavujeme přes proměnné prostředí (Environment Variables).
  • Automatické stahování: Image si sám stáhne požadovanou verzi Minecraftu i Javy.

Blok 2: Konfigurace docker-compose.yml

Struktura souboru docker-compose.yml


version: '3.8'

services:
  mc-server:
    image: itzg/minecraft-server:latest
    container_name: mc-server
    ports:
      - "25565:25565"
    environment:
      EULA: "TRUE"
      TYPE: "PAPER"
      VERSION: "1.20.4"
      MEMORY: "2G"
      MOTD: "Vítejte na Letní škole sítí!"
      MAX_PLAYERS: "20"
      DIFFICULTY: "normal"
    volumes:
      - ./data:/data
    restart: unless-stopped

Přehled klíčových Environment proměnných

Proměnná Výchozí / Příklad Popis
EULA "TRUE" Souhlas s licencí Mojang EULA (Povinné!)
TYPE PAPER / SPIGOT / VANILLA Typ Minecraft serveru (Paper doporučen pro výkon)
VERSION LATEST / 1.20.4 Verze hry Minecraft
MEMORY 1G / 2G / 4G Maximální alokovaná operační paměť RAM
MOTD "Text zprávy" Zpráva dne zobrazená v seznamu serverů
OPS "student,lektor" Seznam hráčů s administrátorskými právy (OP)

Blok 3: Úložiště (Volumes) & Síťové Porty

Mapování síťových portů

  • Minecraft Java Edition používá standardní port 25565 (TCP).
  • Zápis v Docker Compose: - "25565:25565"
    • První číslo: Port na vašem počítači (Host).
    • Druhé číslo: Port uvnitř kontejneru.
  • Tipy Pokud chcete na 1 počítači spustit 2 servery:
    - "25565:25565" (1. server)
    - "25566:25565" (2. server — dostupný na portu 25566)

Persistence dat — Proč potřebujeme Volume?

Kontejnery jsou ze své podstaty stateless (bezstavové).

Bez namapované složky se při zastavení kontejneru smaže celý postavený svět i nastavení!

Zápis Bind Mountu:
volumes:
- ./data:/data
Propojí lokální složku ./data na disku se složkou /data v kontejneru.

Co všechno najdeme ve složce ./data?

  • world/ — Hlavní svět (Overworld)
  • world_nether/ — Svět Nether (Peklo)
  • world_the_end/ — Svět End
  • server.properties — Konfigurační soubor
  • plugins/ — Nahrané Spigot/Paper pluginy
  • ops.json — Seznam operátorů serveru
  • whitelist.json — Seznam povolených hráčů
  • logs/ — Soubory protokolu a historie

Blok 4: Spuštění, Logy & Připojení hráčů

Krok 1: Příprava adresáře a souboru

Otevřete terminál a zadejte následující příkazy:


# 1. Vytvoření složky pro Minecraft server
mkdir -p ~/mc-server
cd ~/mc-server

# 2. Vytvoření konfiguračního souboru
nano docker-compose.yml

Vložte připravenou konfiguraci z Bloku 2 a uložte soubor (Ctrl+O, Enter, Ctrl+X).

Krok 2: Spuštění serveru v kontejneru

Spusťte server na pozadí příkazem:


docker-compose up -d
Co se v tuto chvíli děje:
  1. Docker stahuje obraz itzg/minecraft-server:latest z Docker Hubu.
  2. Automaticky se stáhne Paper Minecraft server verze 1.20.4 a OpenJDK 17.
  3. Generuje se nová mapa světa.

Krok 3: Sledování logů a stavu startu

První start serveru trvá cca 30–60 sekund. Sledujte průběh v živém logu:


docker-compose logs -f

Server je připraven, jakmile se v logu objeví zpráva:


[Server thread/INFO]: Done (18.421s)! For help, type "help"

Sledování logů ukončíte stiskem Ctrl+C (server zůstane běžet na pozadí).

Krok 4: Připojení prvních hráčů

  1. Spusťte Minecraft klient (Java Edition) ve stejné verzi (1.20.4).
  2. Zvolte Multiplayer (Hra pro více hráčů) -> Direct Connection (Přímé připojení).
  3. Zadejte adresu: localhost (nebo IP adresu vašeho Linux PC).
  4. Klikněte na Join Server (Připojit se ke serveru)! 🎉

Blok 5: Správa serveru, RCON & OP Práva

Správa serverové konzole z terminálu

Jak posílat příkazy do spuštěného Minecraft serveru?

Použijeme vestavěný příkaz rcon-cli uvnitř Docker kontejneru:


# Udělení OP práv hráčovi "student"
docker exec -i mc-server rcon-cli op student

# Změna času v hře na den
docker exec -i mc-server rcon-cli time set day

# Nastavení počasí na jasno
docker exec -i mc-server rcon-cli weather clear

Užitečné Minecraft příkazy pro lektory / správa

Příkaz Popis účinku
op <jméno> / deop <jméno> Přidělení / odebrání operátorských (admin) práv
gamemode creative <jméno> Změna herního módu na Tvořivý (Creative)
whitelist on / add <jméno> Zapnutí seznamu povolených hráčů a přidání hráče
kick <jméno> / ban <jméno> Vyhození nebo zablokování hráče ze serveru
tp <hráč1> <hráč2> Teleportace hráče1 k hráči2

Úprava nastavení v server.properties

Soubor se nachází ve složce ./data/server.properties.

Můžete jej upravovat přímo v textovém editoru:


pvp=true
difficulty=easy
max-players=20
allow-flight=true
view-distance=10
enable-command-block=true

Po úpravě souboru restartujte kontejner příkazem: docker-compose restart

Blok 6: Pluginy, Bedrock Podpora & Zálohování

Instalace Pluginů (Paper / Spigot)

Paper server umožňuje rozšiřovat funkčnost pomocí .jar pluginů.

Metoda 1: Ruční nahrání

  1. Stáhněte .jar soubor pluginu (např. LuckPerms, EssentialsX).
  2. Kopírujte jej do složky ./data/plugins/.
  3. Spusťte: docker-compose restart.

Metoda 2: Auto-download

Přidáním do docker-compose.yml:


environment:
  MODRINTH_PROJECTS: "luckperms,essentialsx"

Podpora hráčů z mobilů & konzolí (GeyserMC)

Chcete se k serveru připojit z mobilu (Android/iOS) nebo Xboxu?

  • GeyserMC: Překládá protokoly mezi Bedrock a Java Edition.
  • Stačí v docker-compose.yml publikovat UDP port pro Bedrock: 
    
ports:
  - "25565:25565"     # Java Edition (TCP)
  - "19132:19132/udp" # Bedrock Edition (UDP)
  • Přidejte plugin Geyser-Spigot.jar do složky ./data/plugins/.

Rychlé Zálohování a Obnova světa

Díky namapovaným volumům je zálohování otázkou jednoho příkazu:


# 1. Vytvoření zabalené zálohy světa a konfigurace
tar -czvf zaloha-mc-$(date +%F).tar.gz ./data

# 2. Obnova světa ze zálohy:
docker-compose down
rm -rf ./data
tar -xzvf zaloha-mc-2026-08-11.tar.gz
docker-compose up -d

Samostatné Cvičení pro Účastníky (~30 min)

Zadání praktického úkolu:
  1. Vytvořte novou složku ~/muj-mc-server.
  2. Sestavte soubor docker-compose.yml s následujícími parametry:
    • Typ: PAPER, Verze: 1.20.4
    • Paměť: 2G
    • Vlastní zpráva MOTD: "Váš_Nick - Minecraft Server"
    • Vaše jméno automaticky nastavené v OPS
  3. Spusťte server, sledujte logy a připojte se z Minecraft klienta.
  4. Vyzvejte souseda v učebně, aby se připojil na vaši IP adresu!

Skvělá práce! 🎮

  • Naučili jste se nasadit kompletní Minecraft server během 2 minut.
  • Rozumíte propojení Docker volumů pro trvalou persistenci dat.
  • Umíte spravovat konzoli, přidávat OP práva i pluginy.
