DHCP

Dynamic Host Configuration Protocol

Proč DHCP?

  • Ruční nastavování IP adres je u stovek zařízení nemožné.
  • Zabraňuje konfliktům (duplicitní IP adresy).
  • Umožňuje centrální správu (změna DNS pro celou síť naráz).

Jak to funguje? (DORA)

  1. Discovery: Klient volá „Je tu nějaký server?“ (Broadcast)
  2. Offer: Server odpovídá „Mám pro tebe tuhle IP“.
  3. Request: Klient říká „Super, beru si ji“.
  4. Acknowledgement: Server potvrdí „Ok, je tvoje“.

DHCP Lease (Pronájem)

  • IP adresa není tvoje navždy.
  • Lease Time: Doba, na kterou máš adresu půjčenou.
  • V polovině doby se klient pokusí o obnovení (Renewal).

Co všechno DHCP posílá?

  • IP adresa a maska sítě
  • Výchozí brána (Default Gateway)
  • DNS servery
  • Někdy i jméno počítače nebo časový server (NTP)

DHCP na Linuxu

Klient a diagnostika

Správci sítě

  • NetworkManager: Běžný na desktopech (příkaz nmcli).
  • systemd-networkd: Častý na serverech.
  • dhclient: Klasický nízkoúrovňový nástroj.

Jak získat novou adresu?


# Přes NetworkManager
sudo nmcli device reapply eth0

# Klasicky přes dhclient
sudo dhclient -r eth0  # uvolnění staré
sudo dhclient eth0     # žádost o novou

Kde hledat chybu?


# Logy systému
journalctl -u NetworkManager
# nebo
grep -i "dhcp" /var/log/syslog

DNS

Domain Name System

K čemu to je?

Lidé si pamatují google.com, počítače potřebují 142.250.184.206.

DNS funguje jako distribuovaná databáze, která tento překlad zajišťuje.

Hierarchie DNS


. (Root)
├── com.
│   ├── google.com.
│   └── github.com.
├── cz.
│   ├── seznam.cz.
│   └── nic.cz.
└── org.

Tečka na konci značí absolutní kořen, i když ji běžně nepíšeme.

Typy záznamů

TypVýznam
AIPv4 adresa (jméno -> IP)
AAAAIPv6 adresa
CNAMEAlias (jméno -> jméno)
MXMail Server (kam doručit e-mail)
TXTTextová data (ověření, SPF)

DNS v Linuxu

Resolver — jak se systém ptá

/etc/resolv.conf

Hlavní konfigurační soubor pro překlad jmen.


nameserver 8.8.8.8
nameserver 1.1.1.1
search moje-sit.local

Pozor: Dnes je tento soubor často spravován automaticky (symlink na systemd-resolved).

/etc/hosts

„Lokální DNS“ — má přednost před servery v internetu.


127.0.0.1   localhost
192.168.1.5 muj-server.test

Diagnostika: dig


dig seznam.cz
dig @8.8.8.8 google.com MX
dig -x 8.8.8.8  # reverzní dotaz (IP -> jméno)

Rychlejší alternativy


host seznam.cz
nslookup github.com

Praktické cvičení

1. DHCP Kontrola


# Zjisti, jakou máš IP a jestli je z DHCP
ip a
# Podívej se na logy ohledně DHCP
journalctl -g dhcp

2. DNS Průzkum


# Kdo je tvůj DNS server?
cat /etc/resolv.conf

# Zjisti MX záznamy pro tvůj e-mail
dig google.com MX

# Zkus najít IP adresu seznam.cz pomocí host
host seznam.cz

3. Vlastní hostitel

Uprav /etc/hosts tak, aby adresa moje.lokalka vedla na 127.0.0.1.
